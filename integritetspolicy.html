Integritetspolicy

Den här policyn beskriver hur Caldra hanterar uppgifter som du lämnar via kontaktformuläret på den här sidan.

Vilka uppgifter samlas in

  • Namn och företagsnamn
  • E-postadress och telefonnummer
  • Uppgifter du själv skriver i fritextfältet
  • Tekniska uppgifter som tidpunkt för inskick

Varför samlas uppgifterna in

Uppgifterna används enbart för att kontakta dig om Caldras tjänst, till exempel för att boka in ett samtal eller demo. Ingen data säljs eller delas med tredje part för marknadsföringsändamål.

Hur uppgifterna hanteras

Formuläret skickar uppgifterna till ett internt arbetsflöde (n8n) som används för att kvalificera och följa upp din förfrågan. Uppgifterna sparas endast så länge det behövs för att hantera din förfrågan.

Dina rättigheter

Du har rätt att begära utdrag, rättelse eller radering av dina uppgifter. Kontakta oss via kontaktformuläret för att utöva dina rättigheter enligt GDPR.

Kontakt

Har du frågor om hur dina uppgifter hanteras, hör av dig via kontaktformuläret på startsidan.
